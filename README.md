## ⚡ Quickstart Overview

### 1. Clone the Repository
```bash
git clone https://github.com/DARKPHOENIX2530/autonomous-developer-workflows.git
cd autonomous-developer-workflows
```

### 2. Run Any Episode Demo

* **Part 1 (RAM Benchmark & Cloud Offload)**:
  ```bash
  cd 01-local-ram-overload
  python ram_benchmark_cloud_offload.py --mode compare
  ```

* **Part 2 (Claude vs Antigravity Setup)**:
  Inspect the architecture breakdown in [`02-claude-vs-antigravity/comparison_matrix.md`](02-claude-vs-antigravity/comparison_matrix.md) and agent orchestration in [`02-claude-vs-antigravity/agent_setup.yaml`](02-claude-vs-antigravity/agent_setup.yaml).

* **Part 3 (Autonomous Next.js 14 Local Scaffolder)**:
  ```bash
  cd 03-nextjs-autonomous-scaffolding
  python scaffold_and_deploy.py --name my-app
  ```

* **Part 4 (Background Task Rate Limit Orchestration)**:
  ```bash
  cd 04-autonomous-background-pipelines
  python autonomous_pipeline_orchestrator.py
  ```

* **Part 5 (Autonomous Verification & Self-Healing Patch)**:
  ```bash
  cd 05-autonomous-code-verification
  python verify_and_patch.py --target sample_broken_app.py
  ```

* **Part 6 (Autonomous Production Incident Response)**:
  ```bash
  cd 06-autonomous-production-hotfixes
  python hotfix_and_pr.py
  ```

* **Part 7 (Top 3 AI Coding Tools Matrix)**:
  ```bash
  cd 07-top-3-ai-coding-tools
  python compare_tools.py
  ```

* **Part 8 (Multi-Agent Code Review Fleet)**:
  ```bash
  cd 08-multi-agent-code-review
  python review_fleet.py
  ```

* **Part 9 (Autonomous Database Migration Guard)**:
  ```bash
  cd 09-autonomous-database-migrations
  python migration_guard.py
  ```

* **Part 10 (Fullstack End-to-End Autonomous QA Agent)**:
  ```bash
  cd 10-autonomous-browser-testing
  python autonomous_e2e_tester.py
  ```
